# 📊 Daikibo Telemetry Analysis Dashboard

A professional Power BI dashboard built to monitor and analyze IoT telemetry data from Daikibo manufacturing facilities. The dashboard provides insights into device health, temperature monitoring, geographical distribution, and operational status across factories.

---

## 🚀 Project Overview

This dashboard was developed to help stakeholders monitor:

- Device Health Status
- Temperature Trends & Threshold Alerts
- Factory Performance
- Device-Level Monitoring
- Geographical Distribution of Devices
- Operational Health Metrics

The dashboard follows a clean Deloitte-inspired design with a focus on business storytelling and KPI-driven insights.

- Device health and temperature trends can be monitored in real time.
